# ulearning-monkey 

一个针对优学院的自动刷课脚本

## 使用方法

1. 在浏览器里准备Tampermonkey（油猴脚本) 插件

2. 创建新脚本

3. 把 [ulearning-auto.user.js](./ulearning-auto.user.js) 里面的内容粘贴进去

4. 打开优学院网站，脚本自动启动

## 限制

脚本目前只能刷课，**不能**自动做题

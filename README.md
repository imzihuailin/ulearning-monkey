# 优学院自动刷课助手（油猴脚本）

在 `ua.ulearning.cn` 的课程学习页自动播放视频、自动翻页、自动处理各类弹窗。
**只刷视频和翻页，不答题、不伪造任何学习记录。**

## 安装

1. 浏览器装 Tampermonkey（油猴）。
2. 新建脚本，把 `ulearning-auto.user.js` 的内容整份粘进去，保存。
3. 打开课程学习页，左上角会出现面板。

## 用法

面板上只有三个按钮：

| 按钮 | 作用 |
|---|---|
| **开始** | 开始刷课；暂停之后再点它即续跑 |
| **暂停** | 停止脚本**并且真的把视频暂停** |
| **收起** | 折叠/展开日志区 |

倍速下拉只有 **8x** 和 **16x** 两档，默认 8x。

- 8x 是稳妥档。
- 16x 顶着平台自己的防拖拽阈值；一旦被平台回退或停滞，脚本会自动对半降档。
- **刷课期间请保持标签页在前台**，后台标签会被浏览器节流，实际速度会掉。

### 它会自动做的事

- 视频自动播放、自动维持倍速；
- 平台自己把视频暂停了（网络抖动、"离开太久"）→ 看门狗自动续播并点掉弹窗；
- 翻页、点掉"题目未完成/章节未完成"弹窗；
- 遇到习题**自动跳过，不作答**；
- 刷完整门课 → 状态变「已完成」、日志打出 `✅ 课程刷完啦！🥳`。

### 它不会做的事

- 不点任何选项、不交卷、不读题干；
- 不伪造学习时长、观看进度或完成状态；
- 遇到**必答题**会停下来，状态显示「需要你作答」，等你作答完再点「开始」继续。

## 关于必答题

有些习题弹窗只给「重看视频」，没有「继续视频」——这类是**必答题**。
平台的规则是「题目全部答对才能继续观看视频哦」，脚本没有合法出口可言，所以它会停下、把控制权交还给你。

## 完成的判定

每章/每节结束时平台会盖一张结算卡。脚本的判据是**卡上有没有前进按钮**：

- 有「下一章/下一节」→ 点它继续；
- 没有 → 判定整门课刷完，**不点「关闭」**（`closeStatPage` 内部是 `goPreviousPage()` 两次，点掉会把你导航回内容页），
  只把状态置为「已完成」并停下，那张"恭喜完成"的卡留在屏幕上当确认。

次级兜底：平台自己的 `nextPageName()` 等于 `noMessage.noMore` 时，同样判定刷完。

## 开发

```bash
npm install     # 只装 jsdom（测试用）
npm test        # 20 条回归测试
```

- `ulearning-auto.user.js` —— 脚本本体（唯一交付物）
- `fixtures/page.html` —— 从线上真实标记提取的夹具
- `test/helpers/harness.js` —— jsdom 环境，**注入磁盘上的真实脚本**（不是快照）
- `test/page.test.js` —— 回归测试

选择器和数据模型都逐字对照线上代码（`learnCourse version=2608204`）校验过：
`page.html`、`components_pageView_pageView.html`、`components_questionView_questionView.html`、
`js_learnCourseViewModel.js`、`js_model_Page.js`、`js_model_Section.js`、`js_tools_Timer.js` 等。

## 已知限制

- 只在**视频页**上能加速；PPT/文档类阅读页的停留时长由平台按挂钟累加，脚本无法也不该去篡改。
- 视频的实际倍速上限是浏览器 `playbackRate` 的 16x。
- 真实登录态的时序问题无法靠单元测试覆盖，需上机验证。
